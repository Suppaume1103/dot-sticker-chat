opens─[STATE1 作画/広場保存/ポップ]→closes─[STATE2 鑑賞/チャット保存のみ]→expires─[失効・フィールド入替]→次のお題

■ 保存数で育つ広場（もう一つの背骨）
保存 0-4 / 1×1→5-19 / 2×2→20-49 / 4×4→50+ / 10×10 殿堂級
その場で育つ（引っ越さない）／ブロック=11×11マスに余白を内包して非接触を保証／サイズはDBに持たず保存数からコード導出／失効で全リセット・次のお題は全員1×1から。閾値5/20/50は定数で後調整可。

注 これは低忠実度ワイヤー（構造・配置・状態・invariant対応の確認用）。色/フォントは実装フェーズで作り込む。固定16色のパレットは画面4に仮置き。広場の点在絵は実装では各ブロックに実際の16×16ドット絵本体が描画される。交換機能・キラ版・グループチャットは今回の提出スコープ外。
